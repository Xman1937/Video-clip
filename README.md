ClipFetch - Video Downloader

ClipFetch is a responsive video downloader website built with React, Vite, Node.js, Express, and PostgreSQL.

Features

- Mobile-friendly interface
- Backend API with Express.js
- PostgreSQL database support
- Railway deployment configuration
- Health-check endpoint
- Ready for future migration to Hostinger

Tech Stack

- Frontend: React and Vite
- Backend: Node.js and Express.js
- Database: PostgreSQL
- Hosting: Railway

Deployment

See "RAILWAY-HOSTINGER-DEPLOY.md" for deployment instructions.

Important

Only download videos you own or have permission to download. Platform-specific downloads require authorized integrations and must follow the relevant platform's terms.
